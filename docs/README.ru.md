# ДИЗАЙН / DESIGN — интерактивный RU/EN-дашборд

Полноценный статический сайт по обновлённому макету Figma «Дашборд» для аттестации дизайнера e-commerce. Все данные встроены в код из макета; подключение к живой аналитике Ozon не требуется и **не реализовано**.

## Как открыть

**Быстрее всего:** откройте файл `dist/index.html`, который находится в архиве. Он содержит все CSS, JS и SVG-иконки внутри одного документа. Интернет не нужен для функциональности, а при его наличии автоматически подгружается шрифт Plus Jakarta Sans.

**Версия с исходниками:** откройте `index.html` из корня проекта двойным щелчком либо запустите из каталога проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Сайт можно опубликовать на любом статическом хостинге (например, GitHub Pages, Netlify, Vercel, Nginx) без сборки.

## Что работает

- 4 главных раздела: **Что сделала / Work**, **Достижения / Achievements**, **Проблемы / Challenges**, **Планы / Plans**.
- 11 основных экранов плюс 4 дополнительных аналитических экрана по макету Figma — **15 экранов на каждом языке**.
- Переключение RU / EN в боковой панели и в мобильной шапке с сохранением открытой страницы.
- Переходы по кликабельным вкладкам, история браузера, прямые адреса страниц через хэш.
- Интерактивные диаграммы: выбор столбца, всплывающие значения, анимация появления и счётчиков.
- Фильтры в дополнительных аналитических экранах: месяц, формат карточки, кампания, период и метрика.
- **Кастомный курсор:** светящаяся точка, плавно догоняющее кольцо, расширение и подпись `OPEN` при наведении, короткий эффект нажатия. На телефонах и при `prefers-reduced-motion` используется обычный курсор и отключаются избыточные анимации.
- Экспорт текущих метрик в CSV и копирование прямой ссылки.
- Мобильная панель и клавиатурная навигация.
- Адаптивность для больших экранов, ноутбуков, планшетов и телефонов.

## Управление

- **Клик** по разделу/вкладке — переход.
- **RU / EN** — сменить язык, сохранив текущую страницу.
- **Alt + ← / →** — переход по соседним вкладкам внутри раздела.
- **1, 2, 3, 4** — сразу открыть соответствующий основной блок.
- **Escape** — закрыть мобильное меню.
- **CSV** — скачать метрики и исходную детализацию.

## Адреса

Оригинальный русский экран: `#/work/all`.

Тот же экран на английском: `#/en/work/all`.

Пример плана на английском: `#/en/plans`.

Подробные данные: `#/details/overview`, `#/details/cards`, `#/details/ads`, `#/details/traffic`. В английской версии добавьте `en/` после `#/`.

## Про данные

В разделах «Проблемы» и «Планы» сохранены последние согласованные формулировки из Figma. **Никакое конкретное количество тестов на 2027 год не обещается**: частота определяется после пилотной проверки. Данные о посещениях и показах являются историческими результатами из макета, а не потоком реального времени.
